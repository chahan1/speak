# 🗣️ 道地口說轉譯器 v1.1

說中文 → 語音辨識 → 有錯字就用鍵盤改 → AI 轉成**母語人士真的會講的口語英文**。

## 主要功能
- **🎤 一鍵錄音（v1.1 改良）**：按一下開始說中文，**偵測到你說完（停頓幾秒）就自動結束**，不是用時間限制。
  - **Whisper 錄音辨識**（有 Groq 金鑰時預設使用）：先完整錄音，說完再整段辨識，**不會中途斷掉、不會出現重複的字**，最長 5 分鐘。按鈕外圈的紅色光圈會跟著音量跳動。
  - **Chrome 即時辨識**（備用）：邊說邊出字；已改成一句一句接續，並自動過濾 Android 重複送出的句子。
  - 「⚙️ 設定」可調整：停頓 1.5／2.5／4／6 秒自動結束，或改成自己按停止。
- **✏️ 可修改**：辨識結果放在文字框，可以用注音或任何輸入法修改，也可以直接打字。
- **✨ 道地轉譯**：AI 先理解你的意思（自動修正辨識錯字、去掉「呃、那個、就是」），再用口語英文說出來：
  - 最道地的一句（大字）
  - 其他說法：更隨性／比較客氣
  - 🔑 道地用語解說
  - ⚠️ 中式英文陷阱（說明一般人容易直翻成什麼、為什麼不道地）
- **情境**：朋友閒聊／同事日常／禮貌一點；**美式／英式**。
- **微調**：😎 再口語一點、🙂 客氣一點、✂️ 更簡短、🔄 換個說法。
- **🔊 AI 真人語音（v1.1）**：和英語學習筆記本一樣，可選 **免費 AI 語音（Free.ai，7 種聲音）**、Gemini 語音（8 種）或手機語音。每句只產生一次並存在手機裡，之後重播不花費、離線也能播。同一個網站時，和英語筆記本**共用語音快取**。
- **▶️ 例句連續播放（v1.1）**：左下角「▶ 播放例句」：
  | 設定 | 選項 |
  |---|---|
  | 範圍 | 全部／⭐ 收藏／今天／最近 7 天 |
  | 內容 | 只播主句／主句＋其他說法／再加道地用語 |
  | 順序 | 新的在前／舊的在前／🔀 隨機（10、20、30 句或全部） |
  | 每句念幾次 | 1／2／3／5 |
  | 句子間隔 | 1～8 秒（每念完一次就停頓，適合跟讀） |
  - 播放列可暫停、上一句／下一句、停止、即時調整語速；**AI 語音可關閉螢幕繼續播放**，鎖定畫面也有播放控制。
  - 每筆轉譯結果也有「▶ 整組播放」，一次念完主句、其他說法和道地用語。
- **📒 紀錄**：每次轉譯自動存下來，可搜尋、⭐ 收藏、刪除；點一下紀錄就能重新開啟。
- **💾 備份**：☁️ 分享到 Google Drive（.txt）、📥 下載 .json、📂 還原（重複的會略過）。

## 放到 GitHub Pages（建議：和英語學習筆記本放同一個網站）
1. 打開 `chahan1/chahan1.github.io` 倉庫 → **Add file → Upload files**。
2. 先建一個資料夾 `speak`，把本資料夾所有檔案上傳到 `speak/` 裡面，按 **Commit changes**。
3. 1～2 分鐘後打開：**https://chahan1.github.io/speak/**
4. 因為和英語學習筆記本是**同一個網站**，筆記本裡設定過的 Groq／Free.ai／Gemini 金鑰會**自動共用**，不用再填一次。

> 也可以放在獨立的倉庫，只是要在 App 裡重新設定金鑰（⋮ →「🔑 AI 金鑰設定」）。

## 安裝到手機
- 用 Android 的 **Chrome** 開啟網址 → ⋮ →「加到主畫面」。
- 要做成 APK：到 PWABuilder 輸入 `https://chahan1.github.io/speak/`，步驟和每日工作記錄表相同。
- 第一次按 🎤 時，請允許麥克風權限。

## 注意事項
- 語音辨識需要網路；請用 Chrome 開啟（LINE、FB 內建瀏覽器不能錄音）。Whisper 辨識需要 Groq 金鑰（免費），沒有金鑰時會自動改用 Chrome 即時辨識。
- 設定裡可以把辨識語言改成「中文（中國大陸）」或「粵語」，說明文字可以改成简体中文。
- 朗讀聽起來很機械的話：手機「設定」搜尋「文字轉語音」，改用 **Google 語音服務**並下載英文語音。
- 紀錄存在手機的瀏覽器裡，請定期備份。
- **更新程式**：改完 `index.html` 後，把 `sw.js` 第 3 行的 `speak-v1.0` 改成新版本號再上傳。
