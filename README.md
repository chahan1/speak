# 🗣️ 道地口說轉譯器 v1.6

說中文 → 語音辨識 → 有錯字就用鍵盤改 → AI 轉成**母語人士真的會講的口語英文**。

## 外觀與深色模式（v1.6）
- **深色模式**：預設跟著手機的深色／淺色設定自動切換；右上角 ⚙ 設定最上方的「外觀」可以改成一律淺色或一律深色。
- **線條圖示**：標題和按鈕裡的表情符號換成同一套線條圖示；白色「我想說」和黃色「道地英文」兩個泡泡保留，是這個 App 的招牌。
- **顏色**：整理成以品牌藍為主的色票，深色配色由同一組色票自動產生。
- 功能、紀錄、金鑰與語音快取都不變。

## AI 服務：Gemini 為主、免費服務備用（v1.5）

| 用途 | 第一順位 | 失敗或額度用完時 |
|---|---|---|
| 轉譯、審稿、批改 | **Gemini Flash**（付費） | Groq（免費）→ Free.ai（免費） |
| 錄音辨識 | **Gemini**（錄音轉成 WAV 上傳） | Groq Whisper → Free.ai → Chrome 即時辨識 |
| AI 真人語音 | **Gemini 語音** | Free.ai 免費語音（自動挑性別、口音相近的聲音） |

- **省錢模式**：⋮ →「🔑 AI 金鑰設定」→「Gemini 模型」可選「標準（Flash）」或「省錢（Flash-Lite，費用約 1/3）」。這個設定和英語學習筆記本**共用**。
- Gemini 某個模型額度用完（429）會先換同家族的下一個模型，全部失敗才改用免費服務。
- 建議到 Google AI Studio 把金鑰限制成只能從 `chahan1.github.io` 使用，並在 Google Cloud 設定預算提醒。
- 已知限制：Gemini 語音整個掛掉時，會先試完幾個 Gemini 語音模型才換 Free.ai，所以第一次播放會慢幾秒。

## 翻譯正確性（v1.4）
AI 產生的句子會經過兩層檢查，才顯示給你：

1. **本地規則檢查**（不花額度）：移除含有中文的英文、和主句重複的「其他說法」、句子裡根本沒出現的「道地用語」、把正確說法誤當成錯誤的「中式英文陷阱」。
2. **AI 編輯審稿**：用「英文母語編輯＋口譯員」的標準再檢查一次——意思有沒有漏或多加、是不是現在母語人士真的會說的話（不用冷門或過時的俚語）、用語說明是否正確、陷阱是否真的錯。有問題就自動修正，並列出改了什麼。

另外：
- **英文的意思（回譯）**：黃色泡泡裡會把英文翻回中文，你可以自己核對意思是否和原本想說的一致。
- **檢查狀態**：泡泡下方顯示「AI 編輯檢查過」或「已修正 N 處（點開看改了什麼）」。
- **再確認一次**：覺得怪怪的，或舊版產生的句子，按這個按鈕請 AI 以更嚴格的標準重新檢查。
- **模型順序依品質**：Gemini Flash → Groq（gpt-oss-120b）→ Free.ai（小模型，品質最弱，放最後）。
- **溫度分級**：翻譯 0.35、調整語氣 0.6、審稿與測驗批改 0.1，讓檢查和批改更穩定。
- 「設定 → 轉譯品質」可以關掉 AI 審稿（每句少用一次額度，但比較容易出錯）。

**紀錄搜尋**也加強了：中文、英文、回譯、其他說法、道地用語與說明、我的造句都能搜尋；不分大小寫和標點；可以用空白分開多個關鍵字（例如「swamped 回你」）。

## 畫面（v1.3 改版）
- **底部三個分頁**：「說說看」只負責錄音與轉譯；「紀錄」是所有句子；「練習」是今日統計、複習與連續播放（有待複習時分頁上會出現紅點數字）。
- **兩個泡泡**：白色泡泡是「我想說」的中文，黃色泡泡是道地英文，和 App 圖示一致。
- **英文一律用襯線字體**，和中文介面明顯區分，一眼看到要學的內容。
- 黃色泡泡下方四個主要動作：聽、慢速、跟讀、收藏；右上角可複製英文。其他功能（考考我、整組播放、今天用過了、存到筆記本）放在結果最下方。

## 主要功能
- **🎤 一鍵錄音（v1.1 改良）**：按一下開始說中文，**偵測到你說完（停頓幾秒）就自動結束**，不是用時間限制。
  - **錄音辨識**（有 Gemini 或 Groq 金鑰時預設使用；Gemini 優先、Groq Whisper 備用）：先完整錄音，說完再整段辨識，**不會中途斷掉、不會出現重複的字**，最長 5 分鐘。按鈕外圈的紅色光圈會跟著音量跳動。
  - **Chrome 即時辨識**（備用）：邊說邊出字；已改成一句一句接續，並自動過濾 Android 重複送出的句子。
  - 「⚙️ 設定」可調整：停頓 1.5／2.5／4／6 秒自動結束，或改成自己按停止。
- **✏️ 可修改**：辨識結果放在文字框，可以用注音或任何輸入法修改，也可以直接打字。
- **✨ 道地轉譯**：AI 先理解你的意思（自動修正辨識錯字、去掉「呃、那個、就是」），再用口語英文說出來：
  - 最道地的一句（大字）
  - 其他說法：更隨性／比較客氣
  - 🔑 道地用語解說
  - ⚠️ 中式英文陷阱（說明一般人容易直翻成什麼、為什麼不道地）
- **情境**：朋友閒聊／同事日常／禮貌一點；**美式／英式**。
- **微調**：😎 再口語一點、🙂 客氣一點、✂️ 更簡短、🔄 換個說法。
- **🔊 AI 真人語音（v1.1）**：和英語學習筆記本一樣，可選 **Gemini 語音（預設）**、免費 AI 語音（Free.ai，Gemini 失敗時自動備用）或手機語音。每句只產生一次並存在手機裡，之後重播不花費、離線也能播。同一個網站時，和英語筆記本**共用語音快取**。
- **▶️ 例句連續播放（v1.1）**：「練習」分頁的「選擇句子並播放」：
  | 設定 | 選項 |
  |---|---|
  | 範圍 | 全部／⭐ 收藏／今天／最近 7 天 |
  | 內容 | 只播主句／主句＋其他說法／再加道地用語 |
  | 順序 | 新的在前／舊的在前／🔀 隨機（10、20、30 句或全部） |
  | 每句念幾次 | 1／2／3／5 |
  | 句子間隔 | 1～8 秒（每念完一次就停頓，適合跟讀） |
  - 播放列可暫停、上一句／下一句、停止、即時調整語速；**AI 語音可關閉螢幕繼續播放**，鎖定畫面也有播放控制。
  - 每筆轉譯結果也有「▶ 整組播放」，一次念完主句、其他說法和道地用語。
- **📒 紀錄**：每次轉譯自動存下來，可搜尋、⭐ 收藏、刪除；點一下紀錄就能重新開啟。
- **💾 備份**：☁️ 分享到 Google Drive（.txt）、📥 下載 .json、📂 還原（重複的會略過）。

## 🎓 學習功能（v1.2）
把「看懂」變成「說得出口」：

| 功能 | 怎麼用 | 為什麼有效 |
|---|---|---|
| 🙋 **先試說** | 說完中文後，打開「先用英文試說」開關，用自己的英文試一次，再按轉譯。AI 會給分數、說明哪裡好、哪裡要改，並修正你的句子 | 先自己努力想過再看答案，記得最牢 |
| 📅 **今日待複習** | 按 ⭐ 收藏的句子會自動排進複習：當天 → 1 → 3 → 7 → 14 → 30 天。到「練習」分頁按「開始今日複習」 | 間隔重複，在快忘記時複習 |
| 🧠 **口說測驗** | 畫面只出中文，你用英文說出來（或打字），AI 批改意思和自然度；再選「忘了／差一點／會了」決定下次複習日。💡 提示會給字首和關鍵片語 | 看中文說英文＝主動回想 |
| 🎙️ **跟讀練習** | 聽原音 → 錄自己的跟讀 → 對照聽；綠色是說清楚的字，紅色是沒聽清楚的字 | 模仿語調、停頓、連音 |
| ✍️ **換字造句** | 在「道地用語」按 ✍️，用這個片語說一句自己生活中的話，AI 檢查並存到「我的造句」 | 能自己造句才是真的會用 |
| ✅ **我今天用過了** | 在真實對話或訊息中用了這句，就按一下（算一次成功複習） | 真的用出去的句子最難忘 |
| 📊 **每日目標** | 「練習」分頁顯示連續天數、今天新學／複習／收藏進度（目標可在設定調整） | 每天少量、持續 |
| 📖 **存到英語筆記本** | 把道地用語存成筆記本的單字、句子存成例句，可用筆記本的克漏字和報表複習 | 和既有 App 整合 |
| 🗣️ **跟讀模式播放** | 播放設定一鍵設成每句 3 次、間隔 5 秒、0.85x；範圍可選「📅 待複習」 | 零碎時間也能練 |

**建議每天 15 分鐘**：白天想說什麼就錄下來，先試說再轉譯，收藏 3～5 句 → 通勤時用跟讀模式播「今天」→ 睡前按「📅 待複習」做口說測驗。

## 放到 GitHub Pages（建議：和英語學習筆記本放同一個網站）
1. 打開 `chahan1/chahan1.github.io` 倉庫 → **Add file → Upload files**。
2. 先建一個資料夾 `speak`，把本資料夾所有檔案上傳到 `speak/` 裡面，按 **Commit changes**。
3. 1～2 分鐘後打開：**https://chahan1.github.io/speak/**
4. 因為和英語學習筆記本是**同一個網站**，筆記本裡設定過的 Gemini／Groq／Free.ai 金鑰和「Gemini 模型」設定會**自動共用**，不用再填一次。

> 也可以放在獨立的倉庫，只是要在 App 裡重新設定金鑰（⋮ →「🔑 AI 金鑰設定」）。

## 安裝到手機
- 用 Android 的 **Chrome** 開啟網址 → ⋮ →「加到主畫面」。
- 要做成 APK：到 PWABuilder 輸入 `https://chahan1.github.io/speak/`，步驟和每日工作記錄表相同。
- 第一次按 🎤 時，請允許麥克風權限。

## 注意事項
- 語音辨識需要網路；請用 Chrome 開啟（LINE、FB 內建瀏覽器不能錄音）。錄音辨識需要 Gemini 或 Groq 金鑰，都沒有時會自動改用 Chrome 即時辨識。
- 設定裡可以把辨識語言改成「中文（中國大陸）」或「粵語」，說明文字可以改成简体中文。
- 朗讀聽起來很機械的話：手機「設定」搜尋「文字轉語音」，改用 **Google 語音服務**並下載英文語音。
- 紀錄存在手機的瀏覽器裡，請定期備份。
- **更新程式**：改完 `index.html` 後，把 `sw.js` 第 3 行的 版本號（例如 `speak-v1.2`）改成新的再上傳。
